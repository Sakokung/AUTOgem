# AUTOgem — Local Desktop

โปรแกรมเปิดเป็นหน้าต่างบนคอมพิวเตอร์โดยตรง ไม่เปิด web server และไม่ต้องใช้ browser

```powershell
python -m pip install -r requirements.txt
python app.py
```

หน้าต่างเดียวรวมภาพกล้อง, การขับรถและ Auto, Gripper, การปรับ HSV พร้อม Mask
Preview และการตั้งค่าขอบสนาม โดยใช้ `hsv_colour_config.json` และ
`field_config.json` เดิม
