SKY ROBOT · หน้าต่างเดียวสำหรับกล้องสนาม/ปุ่มรถ/ปรับ HSV/ตั้งสนาม

1) แตก ZIP ลงโฟลเดอร์ใหม่ในเครื่อง Windows (อย่ารันจากใน ZIP)
2) เปิด Terminal ในโฟลเดอร์นี้ แล้วติดตั้ง:
   python -m pip install -r requirements.txt
3) ถ้า ESP32 ใช้ IP อื่น ให้ตั้งค่าใน PowerShell ก่อนรัน:
   $env:ESP32_IP="10.44.166.203"
4) รัน: python app.py
5) เปิด http://127.0.0.1:5000

หน้าต่างหลัก: ภาพกล้องสนามด้านซ้าย แท็บด้านขวา 3 แท็บ
- ควบคุมรถ: ปุ่มขยับ (กดค้าง/ปล่อยหยุด), Gripper, ความเร็ว, มุม Servo
- ปรับสี HSV: เลือกสี คลิกกลางหิน 2–3 ก้อน ปรับ Slider ดู Mask บนภาพ
  ภาพขาวดำใต้ภาพสนามแสดงสีที่เลือก: ขาวคือพิกเซลที่ผ่าน HSV ดำคือไม่ผ่าน
  เปลี่ยนสีหรือเลื่อน Slider แล้วภาพปรับตามทันที; Min/Max area ไม่ส่งผลต่อภาพนี้
  กด "บันทึก HSV JSON" เพื่อเก็บ hsv_colour_config.json; เมื่อกลับแท็บ
  ควบคุมรถ โปรแกรมตรวจหินใช้ค่า JSON ที่บันทึกแล้วทันที
- ตั้งสนาม: คลิก 4 มุมเป็นขอบเขตบนภาพเต็ม ไม่มีการตัด/ยืดภาพ;
  กด "คลิกวงสี" เลือกสีและคลิกกลางวง ตามด้วยขอบวง ทีละสีจนครบ;
  กดบันทึกเป็น field_config.json

โปรแกรมใช้กล้องสนามหมายเลข 1 ตามเว็บเดิม ถ้ากล้องอยู่หมายเลขอื่น:
   $env:FIELD_CAMERA="0"
   python app.py
ระบบปุ่มรถยังใช้คำสั่ง TCP F/B/L/R/S, SO/SC และค่ามุมเดิมของ app2.py
จากเว็บเดิม ไม่มีการอ่านท่ามือและไม่ต้องใช้ hand_landmarker.task หรือ mediapipe

ทดสอบหน้าเว็บด้วยภาพตัวอย่างโดยไม่สั่งรถ (PowerShell):
   $env:FIELD_IMAGE="example_field.png"
   python app.py
ตัวอย่างนี้ปิดคำสั่งขยับและ Gripper ต้องลบตัวแปร FIELD_IMAGE หรือเปิด
Terminal ใหม่ก่อนใช้กล้องและรถจริง

ข้อจำกัดที่ยังต้องแก้ต่อ
- Auto เลือกหินนอกวงที่ใกล้ปลาย Gripper ของ ArUco ID 0 แล้วคีบ
  จากนั้นพาไปปล่อยในวงสีเดียวกัน ต้องตั้งวงสีนั้นและเห็น ID 0 เพียงคันเดียว
  (ภาพตัวอย่างมี ID 0 สองคันจึงไม่เริ่ม Auto)
- การจุ่มและ Slider เป็นค่าเริ่มสำหรับทดสอบ ต้องดูภาพสนามจริงว่าจับหินครบ
  โดยไม่จับพื้น/ขอบสนามก่อนใช้งาน
- ค่ารูปสนามเดิมเป็นภาพที่ถูกปรับมุม จึงไม่ได้ยกพิกัดวงเก่าเข้าโปรแกรมนี้
  ให้คลิกวงใหม่บนภาพเต็มที่กล้องแสดง
- previous_hsv_colour_config.json คือสำเนาค่าจาก RAR เดิมที่มี min/max
  ของ CYAN แคบมาก; ไฟล์ที่โปรแกรมโหลดเริ่มจากค่าพื้นฐานเพื่อให้จุ่มใหม่

เป้าหมายใกล้ปลาย Gripper (แสดงผลเท่านั้น)
------------------------------------------
ในแท็บควบคุมรถ ภาพกล้องสนามจะแสดงวงขาวรอบหินที่ตรวจพบและอยู่นอกวงสี
ซึ่งใกล้ปลาย Gripper ของ ArUco ID 0 ที่สุด พร้อมเส้นขาวและข้อความ TARGET
ทุกสีมีสิทธิ์เป็นเป้าหมาย ข้อมูลนี้ไม่ได้ส่งคำสั่งขับรถอัตโนมัติ
ถ้ามองไม่เห็น ArUco ID 0 หรือมี ID 0 ซ้ำสองตัว ระบบจะไม่แสดงเป้าหมาย
ทดสอบโดยเปิดกล้องสนาม ขยับรถด้วยปุ่มหรือด้วยมือ แล้วดูวงขาวย้ายตามตำแหน่ง
หากย้ายไปใช้กับโฟลเดอร์เดิม ให้ใช้ app.py, vision_panel.py,
auto_approach.py และ templates/index.html จากชุดนี้ร่วมกัน
โดยโฟลเดอร์เดิมต้องมี auto_vision_gem_camera_v4_1.py รุ่นที่มี choose_nearest_target

ทดลองให้รถวิ่งไปหาหิน (ต้องมีกล้องจริง)
-------------------------------------
1) หยุดเว็บเดิมด้วย Ctrl+C แล้วเปิดเว็บชุดนี้ด้วย python app.py
2) ตรวจว่า PowerShell ไม่ได้ตั้ง FIELD_IMAGE และเปิดกล้องสนามในเว็บ
3) วางหินแยกจากสิ่งอื่นให้มีเส้นทางโล่ง เห็น ArUco ID 0 เพียงคันเดียว
4) ตั้งความเร็วล้อให้ต่ำด้วยแผงปรับความเร็ว ทดสอบปุ่มซ้าย/ขวาว่าหมุนตามชื่อ
5) กลับแท็บควบคุมรถ ปิดการควบคุมด้วยปุ่ม แล้วกด เริ่มทดลองวิ่ง
   รถจะสั่ง L/R/F ทีละ 0.12-0.18 วินาที และสั่ง S หลังทุกช่วง
   ตรวจภาพใหม่ก่อนสั่งต่อ หยุดก่อนหินประมาณ 28 px หรือ 0.7 เท่าของด้าน Marker
   อย่างใดมากกว่า แล้วคีบไปปล่อยในวงสีเดียวกัน สูงสุด 35 วินาทีหรือ 60 ช่วง
6) กด หยุด Auto หรือปุ่ม หยุดรถ ด้านบนได้ตลอดเวลา
ระบบหยุดถ้าภาพไม่อัปเดต มองไม่เห็น ID 0/เป้าหมาย หรือรถไม่ขยับหลังสั่ง
ยังไม่มีการหลบสิ่งกีดขวาง จึงต้องจัดเส้นทางระหว่างหินกับวงสีให้โล่ง
